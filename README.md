# Portfólio — Daniel Soares

Projeto web estático organizado em HTML, CSS e JavaScript.

## Estrutura

```text
daniel-soares-portfolio/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   ├── js/
│   │   └── script.js
│   └── images/
│       ├── hero.jpg
│       └── sobre.jpg
└── README.md
```

## Executar localmente

Abra `index.html` no navegador. Para desenvolvimento, é recomendado usar a extensão Live Server no VS Code.

## Publicação

A estrutura é compatível com hospedagem estática, incluindo GitHub Pages.
